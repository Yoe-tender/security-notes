# security-notes
> Network Security & CTF Study Notes
网络安全与CTF学习笔记仓库，用于记录学习笔记、漏洞复现、EXP脚本、靶机实验。

## 仓库简介
本仓库为个人学习存档，记录Web安全、密码学、逆向、PWN、Misc等CTF方向学习资料、解题EXP、漏洞复现实验记录。
所有内容仅用于安全学习研究，禁止未授权的攻击行为。
